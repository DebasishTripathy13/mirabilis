Burst-length sweep, same model and prompt, only the CPU frequency governor
changed. Memory-bound decode stalls on RAM; a scheduler-driven governor reads
those stalls as idleness and downclocks, so the compute between stalls runs
slow too.

Under powersave, P-core frequencies sampled mid-generation:
  cpu0 400 MHz   cpu2 400 MHz   cpu4 3386 MHz
  cpu6 3878 MHz  cpu8 4225 MHz  cpu10 400 MHz

Half the fast cores sat at 400 MHz against a 4.9 GHz ceiling while work was
in flight. Short replies never escape the ramp, which is exactly the
interactive case.
